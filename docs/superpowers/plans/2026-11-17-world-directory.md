## 责任区与验收

1. 实现 `world/` 独占锁、版本化文件 TimelineStore、不可变节点和对象、原子根清单、可读视图与崩溃恢复。
2. 校验普通邻接与 polygon、完整校验每个节点的 delta；保持历史 fork/save/discard 语义。
3. 将 `world/imports/` 内的旧 SQLite 世界显式迁移到原生文件，保留源库和节点/状态 hash；验证真实 Magna 地图和重启读取。
4. 接入 AgentLib GM stdio MCP：查世界/节点/实体、打开工作副本、批量预览/应用、save/discard、fork、导出；身份、角色、资源、幂等和批量原子性由应用实现。
5. 测试单世界锁、进程中断前后恢复、回执重试、缓存缺失、破损文件、版本、迁移、权限和 MCP 端到端；更新 README/STATUS 并实际记录命令结果。

ORBAT/INFO 领域运行时按后续阶段实现，文件格式设计预留其归属。只读预览的人机界面和额外 SQLite 索引不作为本阶段前提。
