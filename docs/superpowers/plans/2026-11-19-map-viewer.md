# 只读地图查看器实施计划

> **状态**：已完成（2026-11-19）
> **日期**：2026-11-19
> **本文性质**：实施计划
> **设计**：[只读地图查看器](../specs/2026-11-19-readonly-map-viewer.md)

1. 接入 jar 的独立查看与 GM MCP 组合启动。HTTP 路由调用共享应用服务的已保存节点查询。
2. 实现有洞及多部件的 Java2D 预览与按视口瓦片，使用 JTS 对原始省形命中。输出现有来源提示、州/区域与后勤数据。
3. 打包浏览器页面，实现视口操作、三种着色、后勤图层、地址定位、详情和保存节点切换。
4. 跑全量测试和真实 jar 的浏览器验收。对副本验证 MCP 同进程、草稿隔离、保存后节点切换，记录证据及未验证项到 STATUS。

上述四项已完成。全量 90 项测试通过，真实 Magna 全图通过 Chromium 交互验收，世界副本通过 MCP 保存与新旧节点切换。Windows 端通过正式的 IPv4 回环端口读到真实 `main-0`。证据、启动入口与未验证边界见 [STATUS](../../agents/STATUS.md)。

## 兵牌与编制侧栏

1. 给已保存节点的部署单位投影补齐兵种、层级与国家显示数据。
2. 实现随倍率聚合和展开的兵牌、左侧军队名单及实际和理想编制树。
3. 用同省部署的葡萄牙剧本记录验证交互，用编制测试数据验证排级节点和直属数量显示。

本轮已完成。发布到本地葡萄牙演示节点 `portugal-1936-2`，验证记录见 [STATUS](../../agents/STATUS.md)。
