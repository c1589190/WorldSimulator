## 时钟与旧节点

剧本时钟是节点完整状态的可选字段 `simulationTime`，用无时区的 ISO 日期时间，精度到秒。时间线仍以 `(branch, tick)` 定位节点，保存时刻用于审计。常规编辑可同日同秒保存多个节点。初始化时钟或推进分钟数通过 GM 草稿命令，随状态、增量和快照一起保存并参与 hash 校验。新时刻从当前模拟时间向前推进。

旧节点允许时间未知。可选的 `scenario-calendar.json` 按节点地址和状态 hash 绑定有来源的开局日期，随世界导出。旧德波开局和补录使用实际导入清单中的 1936-01-01，界面显示日期精度。在其上出发或推进时以该日 00:00 为剧本基点。创世地图底板日期未知。新节点的已提交时钟优先，分支序列从父链的时间变更派生。

## 工具与状态

`edit_open → edit_apply → edit_save` 是唯一写入路径。`edit_apply` 接受以下命令，可在同一草稿按顺序预览、应用，或放弃。

| 命令 | 载荷与效果 |
|---|---|
| `setSimulationTime` | `time` 是 ISO 日期时间，引入剧本时钟。已存在时钟的节点用推进命令。 |
| `startMarch` | `address` 是单位地址，`route` 是包含起点的同节点省份地址数组。以草稿当前部署、编制和地形核对，使用实际编制最低速度与已配准的段长生成行军记录。 |
| `advanceTime` | `minutes` 是正整数。推进全分支时钟及该草稿内所有正在进行的行军。已越过一段用时的单位更新部署省；相邻段累计用时决定何时抵达。 |
| `cancelMarch` | `address` 指定正在行军的单位。保留停止时的路径进度和最后到达省。 |

出发时冻结路线、估算依据、速度和每段耗时。每段向上取整到整秒，最少一秒。有效陆链为共边的普通陆地邻接。无时钟、起点不符、缺段长、速度未知或为零时不能开始。每个单位只保有一条当前或最近的行军记录。途中可取消再规划，进行中直接调整部署需要先取消。控制权等领域变化由 GM 在同一草稿另行裁定。

已接入按进入省判断的通行、地形和补给。对采用新规则的行军，时间推进会按当前授予的许可复核将跨过的路段。[战斗与行军规则](2026-11-20-battle-and-march-conditions.md#跨境通行)

行军记录保存在 ORBAT，包含出发时间、估算速度、来源、各段省 ID 和耗时、可选的停止时间。部署以最后抵达的省为准。行军进度由冻结耗时和剧本时间推得，回放读取同一组输入，不重新估算路线。预览返回将使用的时钟和受影响的单位状态。

## 查询与回放

`timeline_lineage` 和 `GET /api/timeline` 返回分支 head 的根到末端父链。节点可有剧本时刻及精度。保留旧树查询及节点跳转。浏览器以线性节点条带展示日期和地址，切换分支时独立浏览，新旧节点可以前后步进。选中节点后地图和军队读取该节点及 hash。

`world_marches` 和 `GET /api/marches` 读取进度、路线省份地址、折线、计划抵达时刻及来源。地图随时间线节点显示已走和待走段。进行中的标记在当前段插值，部署地址返回实际已抵达省。已抵达的路线可以回看，选中路径可定位并查看所属部队。
