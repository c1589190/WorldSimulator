## 编制速度

原生 ORBAT 节点可经 `putOrbatDocument` 保存 `marchSpeed`。字段包含 `kmPerHour` 与既有 `Evidence`。速度为非负有限数，必须有来源，支持已知、估算和推断。缺少字段表示未知，明确的 0 表示该单位无法行军。字段随编制引用及保存节点回放，旧记录省略它。

按单位引用的编制子树计算。叶节点视为一个行军单位，上级节点有直属人员、装备或明示速度时也计入。只有组织关系的上级节点由下级决定。全支队伍速度为计入节点的最低速度，并列出并列最低的编制节点地址与证据。任一计入节点缺速度时，返回待补节点和未知速度。若已有明确的 0，已能判定队伍无法行军。默认查实际编制。显式选择理想编制可作试算，继承理想引用的版本约束。

## 路线与时间

GM 工具 `world_movement_estimate` 接受单位的完整 `address`，可选 `role`（`actual` 或 `ideal`）和 `route`。省略路线时只计算速度。传路线时使用同节点的省份地址序列，第一项是当前部署省，后续各项须有共享边界的普通陆地邻接。路径和部署都由保存节点提供。

复用有覆盖的 WGS84 配准，按各段两省显示点之间的球面距离估算公里数。总分钟数为各段时间之和，每段用段长除以生效速度再乘 60。生效速度和通行判断见[战斗与行军规则](2026-11-20-battle-and-march-conditions.md)。段长与分钟数保留数值精度。距离来源随路线返回，并标明省间直线估算。缺少配准或段落超出覆盖时，该段公里数未知。速度为 0 时报告无法行军。输入无效时返回路线或地址错误。

结果含单位地址、基准节点及 hash、所选编制和速度证据。最低速度位于 `speed.kmPerHour`，缺项见 `speed.missingSpeeds`。路线返回 `route.distanceKm`、`route.durationMinutes` 和各段，未知数值省略。工具为只读估算。实际推进参照[剧本时钟、行军与线性回放](2026-11-20-simulation-clock-and-marches.md)。

## 验收

- 多层编制和并列最低速度按子树计算。检查实际与理想、未知与 0、旧存档读取、写入和重启回放。
- 校验路线从现部署省出发，拒绝跳省、跨节点及水域。检查有、无配准时的公里数与耗时，并用 1936 实图副本通过 GM MCP 验证。
