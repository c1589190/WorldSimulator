# 1936 欧洲剧本与 Agent 推演

> **用户目标**：[原稿 §19–20](2026-11-17-worldsim-architecture-design-source.md)

## 1. 交付顺序

当前工程排期及已实现范围见[欧洲开局与推演计划](../plans/2026-11-20-1936-europe-workflow.md)。下一阶段先实现带剧本日期的线性时间线。

1. **接入外部地理参考。** 现有 Magna 地图为省形、邻接、铁路和补给节点提供底板。先校准欧洲主图，支持通过地名、别名或经纬度查省，以及查看外部边界。拼图按各自图幅配准。
2. **导入 1936 剧本。** 暂按 1936-01-01 开局。先用德国和波兰测试首都、跨境邻接、实际部署和批量归属，再扩到地图中的主要参战国和邻国。首版核对能影响决策的地图与国家资料，覆盖关键陆军单位、动员状态、外交关系、产能和库存。
3. **跑通多国回合。** 用两个国家验收一个和平回合和一段独立的冲突测试分支。后续扩大国家数和推演长度。首版推演以陆军调动、铁路补给、地区控制、简化生产及外交为主。

## 2. 地理参考与史料口径

外部参考以带坐标系、版本、日期和来源的数据集接入。每个图幅保存控制点、适用范围、变换和独立验证误差。地名先检索候选，坐标变换后用当前省形查询。误差范围跨过多个省边界或地点在已校准图幅外时，返回候选或未知，并带上证据。确认后的省份沿用 `NodeAddress` 和稳定省 ID。首轮配准从 Miller 模型开始复测，已有主图留一试验命中 20/25。[地理调查](../reports/2026-11-19-geography-country-orbat-recon.md)

Natural Earth 提供城市坐标与多语别名，固定版本的 Magna 源文件提供当前地图 ID 对照及开局资料线索。CShapes 2.0 可按日期核对历史国界，当年资料用于核对归属、控制和特殊地位。编制、产能等按相应年代和统计口径查证。CShapes 的资料授权为 CC BY-NC-SA 4.0，来源版本在导入清单保留。[Natural Earth](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-populated-places/) · [CShapes](https://icr.ethz.ch/data/cshapes/) · [联合国历史统计年鉴](https://unstats.un.org/unsd/publications/statistical-yearbook/past-issues/)

史料支持的字段保存来源、日期、状态和置信度。归属与控制分别校核。资料空缺保持未知，供推演使用的抽象值明确归入带版本的剧本参数。

史实贴合贯穿初始状态与逐回合推演。GM 用当时的条件、已核对的历史事件和适用资料推演。与史实发生偏离时，记录相关决策、条件变化及裁决依据。资料如何被找到、提取和核对见[1936 史料查证记录](../reports/2026-11-19-1936-source-research.md)。

首个图幅使用世界目录下可选的 `geo-reference.json`。它是外部查址与边界证据，文件有版本、地图尺寸、基准节点与 hash，并随本地世界导出。覆盖范围取已校对地点的凸包，留出点的坐标只用于检验模型和界定范围。固定基准核对后，坐标命中使用所查询节点的原生省形。明确来源的地名对应返回节点地址，坐标查询投影后按留出误差搜索省形。误差范围界内只有一个省且不触及省界时给出确定命中，其余返回候选或覆盖外状态。该文件提供只读参考，已提交的归属、控制和部署仍按时间线保存。

`world_geo_lookup` 接受可选节点和地名，或经纬度两值，返回参考版本、覆盖和省份候选。也可传入完整省份地址，由当前省内显示点反算 WGS84 近似位置，并列出已校核的地名对应。查看器显示近似位置供外部地图复核，并可叠加有日期与来源的参考边界。

## 3. 剧本导入与实际工具验收

外部采集步骤可生成含来源和日期的候选清单。通过程序内查省、查单位和聚合查询，确认候选对应的实体 ID。导入预览给出匹配、歧义、缺项、归属冲突及覆盖范围。确认项在从 `main-0` 分出的同一草稿内分批预览和应用，统一保存为新节点。按现有单批最多 100 条命令协调调用，最终保存核对草稿版本与基点 hash。保存后查地图、单位、变更和时间线回放。

复用 `world_search`、`world_lookup`、`edit_open`、`edit_apply`、`edit_save` 以及国家、领土和 ORBAT 命令。外部资料的归一化可以重复运行。地图、单位及其他领域状态均通过 `Command → ChangeSet → TimelineNode`。导入过程记录工具调用中遇到的定位、别名、批量校验和反馈问题，先补真实流程碰到的缺口。

## 4. 一个推演回合

1. GM 从同一个已保存节点给各国决策人分发可见信息。程序按 GM 设置返回获准看到的地图、编制、经济、政治、外交和 INFO。简报和后续读取均携带节点地址、hash 与剧本日期。
2. 决策人 Agent 依据能获取的信息自主决策。提交包含本国决策、对象地址、简短理由及基准节点，身份从服务端会话绑定。调动、动员、生产和外交都是待 GM 推演的决策。
3. GM 读取世界状态、各国决策和史料，统一推演回合。GM 给出结果、依据及领域变更。程序校验提交身份、对象引用、基点、版本和状态一致性，并应用完成后的变更。
4. GM 通过现有写入路径保存一个新的时间线节点。领土控制、单位状态、经济、政治和外交各进自己的领域，事件与简报挂在带地址和可见性的 INFO 上。MCP 面板可读各角色获准查看的决策摘要、回执、裁决说明和新节点地址。浏览器切换到该节点查看变化。

建议以周作为初版推进单位，剧本日期和 `(branch, tick)` 明确关联。保存保留原决策、GM 确定的变更和依据，回放直接读取已保存结果。多国推演需补 GM 管理的国别视图、只读查询和决策提交接口。GM stdio MCP 与浏览器查看器现已能在同一进程共用世界服务，现有 MCP 工具面向 GM。[工具声明](../../../src/main/java/io/mosire/worldsim/app/WorldTools.java) · [INFO 设计](2026-11-17-map-orbat-info-timeline-design.md#4-info决策人的结构化感知层)

## 5. 验收

- 从外部地名或经纬度得到有证据的省份地址，核对确定命中、多候选、边界附近和未覆盖图幅。
- 仅通过程序工具从原始地图导入试点的真实剧本资料，出具覆盖与缺项报告，保存后查回归属、部署、来源和旧节点。
- 用两个国家对同一时点分别读取和提交，验证可见范围、国家决策权限、GM 处理竞争决策、保存重试及回合结果节点。
- 在 MCP 看到简报、行动与裁决回执，在浏览器读到同一节点的兵牌和领土等变化。退出并重启后重放结果。

## 6. 首轮实施口径

以 1936-01-01 和德波地理样本验证查证、配准及导入。开局的史实、后续推演输入和已裁决结果均可追溯至证据。阶段切片及初版时长可按实测迭代。

德波首片以同日历史边界和原地图州史共同支持的陆省为归属候选。将省内点到边界的距离与留出误差对照，边界带和来源冲突单列。部队只取定位和时间有来源的指挥部驻地，数量和缺失编制保持未知。德波导入在独立副本分支验收。

## 7. 边界复核、归属调试与师级序列

用户要求「我认为你应该出调试显示模式，方便你和其它AI查看空缺部分并补齐之类的」（2026-11-19）。验收旧节点的连续国界时同时检查实际归属着色、史料边界和未登记的陆省。外部参考的配准误差用于识别复核范围。在同日归属有支撑且地图州成员吻合时，按省级地址填补，逐条保留来源和 `inferred` 状态。来源边界有显著分歧时核对省位置、普通陆地邻接和地方史。以 1936-01-01 的单独地图归属表示但泽自由市。

`geo-reference.json` 可选字段 `territory` 含 `date`、`source` 和从省 ID 到预期国家 ID 的 `owners`。保存节点提供当前归属。MCP 工具 `world_territory_gaps` 支持图源参考范围、全图缺项及任务指定范围。任务用 `countryId` 与 `expectedProvinceIds` 传入一份已独立核对的陆省清单，返回 `checkedProvinces`、`coverage`、`unassigned` 与 `ownershipMismatches`。清单中的 ID 须存在，且指向陆省。无参考、无覆盖、全图已检查、内置史料覆盖和任务范围分别标明。以 `countryId` 过滤的内置查询，即使指定全图，也需要外部参考才能判定待查范围。分页项给出当前与预期国家、稳定 ID、地址和问题种类。查看器「归属调试」着色原有未填省，并在列表区分漏填和归属冲突。审计可信范围由给定参考决定。

瑞典等主图原覆盖外地区可用固定地名坐标与原始地图同名省分别配对，查询原始位图验证省号及误差。已有仿射和历史边界图层沿用，新增区域以已核对地标的凸包与旧覆盖的并集表示；只有证据覆盖到的范围参与计算。核对时将定位坐标、原始省名／号、投影落点、候选和范围留档；误差半径以独立留出点检查，候选冲突时保留多候选。省级部署是否可信仍按史料及地图定位两项判断。查址工具扩展不改写已保存的部署或领土。

师级开局按开局日的现役序列核对完整性。用同时期驻地资料和地图地址定位师指挥部，汇总常备师种类和数量，编制证据足以确认的下属保留在师内。理想编制和实有数量分开记录。地理修正及新部署从 `de-pl-1936-1` 通过 GM MCP 预览并保存为同一分支的新节点。
